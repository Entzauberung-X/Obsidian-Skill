> 七种笔记类型，七种标准模板。每条笔记都必须"有头有尾"：frontmatter 开头 + 知识关联结尾。

本技能覆盖 `考研/数学一/` 下所有笔记的**生成**与**优化**。

- **生成**：按模板新建公式笔记、学习要点、思维导图、专题笔记、二级结论、错题归因、思路轨迹
- **优化**：补全 frontmatter、检测死链、检查 学习要点↔公式笔记 配对、统一风格、**主笔记概念理解注释增强**（给各概念加「为什么」的直观注释）、**思维外化**（把隐性推理变成可审视的对象）

## 数学笔记的本质：思维外化 · 活档案

> 数学笔记的核心价值在于把抽象的数学思维**外化**成可追溯、可迭代的个人知识体系——它是思维发生的"第二次现场"。**写笔记 ≠ 搬运知识，写笔记 = 让思维再发生一次。**

五条贯穿性原则（生成/优化每篇笔记时自检）：

1. **思维外化，非知识搬运**：每条笔记回答 what + why + how——是什么、为什么这样想、我当时怎么理解的。只抄公式 = 没有发生第二次思维。
2. **顿悟必留痕**：凡"想通了"的瞬间必须留下痕迹（`> [!note] 顿悟 ·「...」` 或「思路轨迹」笔记），否则隐性推理不可审视、不可迭代。
3. **错题归因到思维漏洞**：错题不是抄题，而是从"做错的那一步"反推"思维的漏洞"，分类归因 + 对策 + 变式自测闭环。
4. **可追溯**：每个结论能回溯来源（教材/真题/自证）与理解轨迹（原来错在哪 → 现在对在哪）。
5. **活档案·可迭代**：笔记随认知生长——待补充落实后删去并回链；同类顿悟/错因沉淀 ≥3 条升级为专题或二级结论。

> 📖 完整哲学、两类新笔记模板（错题归因/思路轨迹）、一题多解织入、迭代升级规则 → **`references/thinking-archive.md`**。创建错题归因或思路轨迹笔记前必须读它。

## 排版铁律

### 1. 表格内禁用裸 `|`

Obsidian 先解析 Markdown 表格再 LaTeX。**表格单元格的 `$...$` 内严禁出现裸 `|` 字符**——`|` 会被误判为表格列分隔符，导致整张表错乱。

| 场景 | ❌ 错误（表格内） | ✅ 正确（表格内） |
|:---|:---|:---|
| 条件概率 | `$P(B\|A)$` | `$P(B\mid A)$` |
| 条件分布 | `$f_{X\|Y}(x\|y)$` | `$f_{X\mid Y}(x\mid y)$` |
| 绝对值 | `$\|x\|$` | `$\lvert x\rvert$` |
| 范数/模 | `$\|X\|$` | `$\lVert X\rVert$` |
| 集合基数 | `$\|A\|$` | `$\lvert A\rvert$` |
| 条件期望 | `$E(X\|Y)$` | `$E(X\mid Y)$` |

> 🧠 **记忆口诀**：**条件概率用 `\mid`，绝对值用 `\lvert...\rvert`，范数用 `\lVert...\rVert`。**

**注意**：`\|`（反斜杠+管道符）虽然能在部分 Markdown 解析器中逃过表格列分隔检测，但它在 LaTeX 中会被渲染为双竖线 `‖` → 语义错误。**统一使用 `\mid` / `\lvert` / `\lVert` 等显式 LaTeX 命令代替。**

**例外**：`$$...$$` 独立展示公式块不在表格内，可以正常使用裸 `|`。

### 2. 盒装核心公式

必背公式用 `\boxed{}`：
```latex
$$\boxed{\int_a^b f(x)dx = F(b) - F(a)}$$
```

### 3. 表胜于文

对比信息、分类信息、选项速查 → 优先用表格。

### 4. Callout 使用规范

仅使用 7 种，每种有明确用途：

| Callout | 用途 | 示例场景 |
|:---|:---|:---|
| `> [!abstract]` | 定义/一句话定位 | "罗尔定理：两端等高的光滑曲线上至少有一处切线水平" |
| `> [!tip]` | 解题技巧、口诀 | "反对幂指三，u 选前面" |
| `> [!warning]` | 注意事项 | "等价无穷小只在乘除中使用" |
| `> [!danger]` | 易错陷阱 | "洛必达用完必须再次确认条件" |
| `> [!example]` | 例题 | 完整题目 + 解 + 答案 |
| `> [!note]` | 补充说明 / 推导背景 / **理解注释** | 概念直观解释：`> [!note] 理解 ·「口诀名」`；或推导背景 "此公式由链式法则推导而来" |
| `> [!summary]` | 归纳总结（仅知识点结论浓缩，慎用；不写"三句真经/一句话总纲"式总结） | 结论要点 |

- ⭐⭐：高频，多数年份

### 7. 理解注释（概念直观解释）

> 给章节主笔记（基础笔记）中的每个概念添加「为什么」的直观解释——让读者不仅背公式，更懂本质。这是主笔记增强的核心动作，与公式汇总的「🧠 醒脑记忆体系」口诀对齐。

**格式**：

```markdown
> [!note] 理解 ·「口诀名」
> {直观解释：本质/为什么 + 几何或类比直觉 + 操作提示}
```

**放置**：每个概念子节（`### 1.1` 等）的公式块之后、下一个子节之前；若该节已有 `[!tip]`/`[!warning]` 等 callout，注释放在它们**前面**（先本质，后操作）。

**口诀名对齐公式汇总**：优先复用同章公式汇总的 🧠 醒脑口诀，保证全章记忆体系一致——

| 概念 | 口诀名 | 核心直觉 |
|:---|:---|:---|
| 联合分布函数 | 「高维推广」 | 左下无穷象限累计概率；变量 → +∞ 还原边缘 |
| 矩形概率 | 「容斥原理」 | 大矩形 − 两长条 + 小矩形 |
| 联合分布律 | 「二维概率表」 | 格子 = 两事件同时发生概率 |
| 边缘分布 | 「求和/积分去变量」 | 把另一变量加掉 / 积掉 |
| 条件分布 | 「定值归一」「切片归一」 | 固定后组内重新归一化 |
| 独立性 | 「可乘 + 矩形」 | 联合 = 边缘乘积 且 定义域矩形 |
| 卷积公式 | 「拆分积分」 | 把 z 拆成 x+(z−x)，沿直线累加 |
| max/min | 「全≤乘积，至少一补」 | max 交集、min 补集 |
| 一般函数分布 | 「分布函数法万能」 | 画区域 → 二重积分 → 求导 |
| 二维均匀 | 「面积比」 | 几何概型二维升级 |
| 二维正态 | 「五个参数」「仅此一家」 | ρ 定椭圆倾斜；不相关⇔独立仅正态 |

**编写原则**：
- 每个独立概念 **1 条**、**2–4 行**，30 秒可扫读
- 讲「为什么」与直觉（几何图景 / 离散↔连续类比 / 与条件概率同构），**不重复公式本身**
- 与既有 callout 互补：已有 `[!tip]` 讲"怎么操作"，理解注释讲"本质是什么"
- **不新增公式/结论**，只解释既有内容；不修改原文公式、表格、标题
- 某概念已有等效理解（如 `[!abstract] 极值分布的直观理解`）时，补「操作口诀 + 前提」而非重复

## 常见问题

### Q：公式笔记和学习要点的区别？

| 维度 | 公式笔记 | 学习要点 |
|:---|:---|:---|
| 定位 | **查**（查公式/定理） | **懂**（懂策略/脉络） |
| 内容 | 公式、推导、例题 | 考情、框架、决策树 |
| 公式 | ✅ 大量公式 | ❌ 不展开公式 |
| 阅读场景 | 做题时查阅 | 开始一章前阅读 |
| 长度 | 100-300 行 | 80-150 行 |

### Q：什么时候创建专题？

满足任一条件就建：
- 跨 2+ 章的高频考点（如三大公式 Green/Gauss/Stokes）
- 某题型在真题中反复出现（如中值定理证明题）
- 用户明确说"这个要专门整理"

### Q：专题和二级结论的区别？

| 维度 | 专题笔记 | 二级结论 |
|:---|:---|:---|
| 定位 | 方法深挖 | 公式速查 |
| 结构 | 方法总览 + 例题 + 易错点 | 盒装公式 + 表格 |
| 长度 | 150-300 行 | ≤80 行 |
| 例题 | 必须有 | 没有 |
| 使用场景 | 专项突破时深度学 | 考前 10 分钟速过 |

### Q：总目录编号 16/17 为什么是乱的？

历史原因：`17、多元函数积分学` 和 `16、级数` 的章号在部分文件中交叉引用不一致。总目录链接以**文件名**为准（`[[17、多元函数积分学]]` 即文件 `17、多元函数积分学.md`），链接别名可能显示为旧编号。修改只在需要时进行，不追求全改。
