# 数学笔记的本质：思维外化 · 活档案

> 核心定位：数学笔记不是板书实录，也不是题目堆砌，而是把抽象的数学思维**外化**成"可追溯、可迭代"的个人知识体系——它是思维发生的**第二次现场**。写笔记 ≠ 搬运知识，写笔记 = 让思维再发生一次。

## 五条贯穿性原则

| 原则 | 含义 | 在笔记中的落地 |
|:---|:---|:---|
| ① 思维外化，非知识搬运 | 每条笔记回答 what + why + how：是什么、为什么这样想、我当时怎么理解的 | 笔记必须含个人化理解（理解注释/顿悟），禁止只抄公式当"板书实录" |
| ② 顿悟必留痕 | "想通了"的瞬间是认知资产，必须外化，否则隐性推理不可审视、不可迭代 | `> [!note] 顿悟 ·「...」` 或「思路轨迹」笔记 |
| ③ 错题归因到思维漏洞 | 从"做错的题"反推"思维的漏洞"，不是抄题 | 「错题归因」笔记：错因分类 → 思维漏洞 → 对策 → 变式闭环 |
| ④ 可追溯 | 每个结论能回溯来源（教材/真题/自证）+ 推理链 + 理解轨迹 | 知识关联标明来源；理解注释记录"原来错在哪 → 现在对在哪" |
| ⑤ 活档案·可迭代 | 笔记随认知生长，不是一次性成品 | 待补充落实后删去并回链；同类顿悟/错因 ≥3 条升级为专题或二级结论 |

## 新笔记类型

### 类型 6：错题归因笔记 `{ch}.31、错题归因-{主题}.md`

**定位**：把"做错的题"变成"思维的漏洞"。不抄题，而是还原错误思路的走向、精确归因、给出可执行对策、用变式自测闭环。

**错因分类**（归因必须精确到类型，禁止写"粗心大意"这种空话）：

| 错因类型 | 判定标准 | 典型例子 |
|:---|:---|:---|
| 知识性缺失 | 该记的没记住 / 没见过这个结论 | 忘掉 $\int\sec^3 x\,dx$ 的递推公式 |
| 方法性错误 | 知道概念但选错 / 不会用方法 | 该用拉格朗日中值却去洛必达 |
| 计算性失误 | 思路对，执行错 | 换元后忘改上下限 |
| 审题性偏差 | 没读懂条件 / 漏看限制 | 忽略"$x>0$"定义域 |
| 概念性混淆 | 两个概念混为一谈 | 可导↔连续、充分↔必要 |

**模板**：

```markdown
---
tags: [数学一, {板块}, 错题归因, {章名}]
---

# {主题} · 错题归因

> [!abstract] 一句话定位
> **{考点本质} → {典型错误}**：表面是{题型}，真正的坎在{思维漏洞一句话}。

---

## 1. 错题再现

**题目**：{题干}

> [!danger] 我当时是这样想的
> {还原错误思路的"走向"——不是抄错误步骤，而是解释为什么会走到这一步}

## 2. 错因归因（精确到思维漏洞）

| 归因维度 | 内容 |
|:---|:---|
| **错因类型** | {知识性/方法性/计算性/审题性/概念性，可多选} |
| **表面错误** | {具体错在哪一步} |
| **思维漏洞** | {从错误反推：缺了什么认知 / 踩了什么隐含假设} |
| **根源** | {为什么会缺：没记住？没理解？没建立联系？} |

## 3. 正解与踩分步骤

> [!example] 正解
> **解**：{标准解法}
> **答案**：$\boxed{...}$
> **踩分步骤**：{解答题按踩分点分步，算错也能拿步骤分}

## 4. 对策（下次怎么防）

- [ ] {具体可执行的检查动作，动词开头，如"求完驻点必算 Δ=AC−B²"}
- [ ] {触发同类题型的启动条件}

## 5. 变式自测

> [!example] 变式
> **题目**：{同考点、换包装的题}
> **提示**：{关键识别点，不直接给答案}

---

## 知识关联

- [[{章号}、{章名}|源章节主笔记]]
- [[{关联专题}|关联专题]]
```

**编写原则**：
- 一个主题（一道题或一类题）一条；同类错因可合并
- **§1 是灵魂**：还原"我当时为什么这么想"——这是思维外化，不是抄题
- 归因精确到思维漏洞；根源要诚实（没记住/没理解/没建立联系）
- 对策必须可执行（动词开头），不写"下次注意"
- 变式自测同考点换包装，提示给识别点，答案留白

### 类型 7：思路轨迹笔记 `{ch}.41、思路轨迹-{主题}.md`

**定位**：记录"从卡住到想通"的思维转折——顿悟的定格。它是隐性推理变成可审视对象的载体，也是"第二次发生"最集中的体现。

**模板**：

```markdown
---
tags: [数学一, {板块}, 思路轨迹, {章名}]
---

# {主题} · 思路轨迹

> [!abstract] 一句话定位
> **{数学本质} → {我的思维转变}**：记录我从{旧理解}到{新理解}的转折，以及为什么值得记住。

---

## 1. 触发场景

{什么让我卡住 / 困惑：题目、概念、别人的解法}

## 2. 卡点重现（原始路径）

> [!danger] 一开始我这样想
> {初始思路 + 为什么走不通}

## 3. 思路转折点

> [!tip] 转折发生在哪一步
> {是什么点醒了我：反例 / 类比 / 提示 / 几何图景 / 一道题}

## 4. 顿悟瞬间（新理解）

> [!note] 顿悟 ·「{口诀名}」
> {现在看清了什么：本质一句话 + 直觉图景}

## 5. 一题多解（适用时）

| 路径 | 思路一句话 | 本质度 | 稳健度 |
|:---|:---|:---:|:---:|
| 方法A | ... | ⭐⭐⭐ | ⭐⭐⭐ |
| 方法B | ... | ⭐⭐ | ⭐⭐⭐ |

## 6. 可迁移结论

- [ ] {跨题型 / 跨章可复用的策略}
- [ ] {对其它章节的启发}

---

## 知识关联

- [[{章号}、{章名}|源章节主笔记]]
```

**编写原则**：
- 顿悟是**内容**不是鸡汤——必须落到一个可复用的认知（本质 / 策略 / 联系）
- §3 转折点要具体：什么刺激物触发了转变（反例？类比？图景？）
- 一题多解表标注**本质度**（哪个最贴近数学本质）与**稳健度**（哪个最不容易错）
- 每篇 ≤ 120 行，重质不重量

---

## 织入现有模板

### 1. 专题笔记 → 可选 `## 一题多解`

同一道题给 2-3 条路径，用上表（本质度/稳健度）。**价值**：一题多解暴露的是方法的适用边界——这是个人解题策略库的核心资产，与「方法总览表」互补（总览管广度，一题多解管深度）。

### 2. 理解注释 → 可含"理解轨迹"

对反直觉概念，`> [!note] 理解 ·「...」` 内容可含"我原来以为 X → 实际上 Y"。**价值**：把"过去的错误认知"和"现在的正确认知"并列，正是可追溯——读者（未来的你）能看到认知是怎么被修正的。

### 3. 待补充机制 → 活档案迭代升级

| 触发 | 动作 |
|:---|:---|
| 同类错因沉淀 ≥3 条 | 合并为「错题归因」专题，删去各条待补充，回链 |
| 同类顿悟沉淀 ≥3 条 | 升级为「思路轨迹」专题或二级结论，删去待补充，回链 |
| 某待补充落实为笔记 | 删去该行，知识关联加新笔记链接 |

## 判断速查：这条内容算不算"思维外化"？

| ❌ 不是（知识搬运/废话） | ✅ 是（思维外化） |
|:---|:---|
| 抄一遍教材公式，无任何个人注记 | 公式 + 「为什么这样想」的理解注释 |
| 记录"我错了"，原因写"粗心" | 还原错误思路走向 + 归因到具体思维漏洞 |
| "这一题我解出来了" | 记录解法之外：我卡在哪、什么点醒了我、哪条路径更本质 |
| 重复教材已有的"本节重点" | 记录理解轨迹：我原来以为 X → 现在知道 Y |
