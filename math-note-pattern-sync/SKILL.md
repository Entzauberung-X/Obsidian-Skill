# 考研数学一 笔记模式同步

> **核心目标**：将 `02、线性代数/` 中成熟的笔记模式体系，泛化应用到 `01、高等数学/` 和 `03、概率论/`。
>
> **侧重应试**：本体系一切为"考研数学一考场得分"服务——每个知识点都要标清**考什么（考频/题型）、怎么答（得分步骤）、坑在哪（易错/陷阱）**。笔记是考场武器，不是教科书复述。
>
> **为何重要**：线性代数笔记是三个科目中最完整、最系统的——它有统一的编号体系、每章公式汇总、专题深挖、冲刺补充、二级结论、以及跨章节的综合总结。高等数学部分完整、概率论近乎空白，这套技能就是将这棵"模式树"移植过去，让三个科目遵循同一套笔记标准，形成真正的"数学一"知识体系。
>
> **模式来源**：本技能从 `engineering-math-organizer`（`数学/工程数学/`）移植了五项强机制并针对考研适配：**① 考点本质优先原则**、**② 章节主笔记模板**、**③ 待补充记录机制**、**④ 健康检查清单 + 死链检测脚本**、**⑤ 安全规则**。
>
> **边界**：`engineering-math-organizer` 侧重**工程应用落点**（数学 → 工程出口）；本技能侧重**考研应试得分**（考点 → 考场拿分）。两者机制同源但目的不同，勿混用。

## 数学笔记的本质：思维外化 · 活档案

> 笔记既是**考场武器**（考什么 / 怎么拿分 / 坑在哪），也是**个人认知档案**——把抽象的数学思维**外化**成可追溯、可迭代的知识体系。它是思维发生的"第二次现场"：**写笔记 ≠ 搬运知识，写笔记 = 让思维再发生一次。**

应试版五条原则（生成/格式化每篇笔记时自检）：

1. **思维外化，非知识搬运**：每条笔记回答 what + why + how。只会背公式不会识别题型 = 白背。
2. **顿悟必留痕**：识别题型特征 / 选定方法的顿悟是得分开关，必须外化（`> [!note] 顿悟 ·「...」` 或「思路轨迹」笔记）。
3. **错题归因到思维漏洞**：从"做错的那一步"反推"思维的漏洞"，分类归因 + 对策 + 变式闭环，并标注真题出处。
4. **可追溯**：每个结论能回溯来源（教材/真题/自证）与理解轨迹（原来错在哪 → 现在对在哪）。
5. **活档案·可迭代**：待补充落实后删行回链；同类错因/顿悟沉淀 ≥3 条升级为专题或二级结论。

> 📖 完整应试适配哲学、两类新笔记模板（错题归因 `{ch}.31` / 思路轨迹 `{ch}.41`）、一题多解织入、迭代升级规则 → **`references/thinking-archive.md`**。创建这两类笔记前必须读它。

## 一、考点本质优先原则（从本质出发）

> 从 `engineering-math-organizer` 移植并针对考研适配：**所有章节/专题/冲刺笔记，一律从考点本质出发组织**，而非从方法清单、题型罗列开始。先讲清"这个概念本质上是哪个数学对象/原理"，再落到"考什么题型、怎么操作"。

### 铁律

1. **先本质，后题型**：每篇笔记（章节主笔记 / 专题 / 公式汇总 / 冲刺）第一节必须先给出该考点的**数学本质**——它本质上是哪个数学对象 / 原理（极限 = 局部逼近、秩 = 维数不变量、全概率 = 分情况讨论的数学化、标准化 = 保序线性变换）。先写定义 + boxed 核心方程，再展开题型与方法。
2. **一句话定位 = 本质 → 考点**：`[!abstract]` 必须写 `**{数学本质} → {考点/题型}**：{本质一句话}`——先讲"用什么数学原理回答什么考试问题"。
3. **禁止以方法清单开篇**：不得用"求极限的七种方法""证明题六大技巧"这类裸清单开篇。方法只能作为**本质在不同函数形态 / 题型下的操作化**出现，而非内容主线。
4. **boxed 核心公式先行（章节骨架）**：核心数学结构（定义、归一性、标准化公式、核心方程）在 `## 0. 汇总速查` 或各节开头用 `$$\boxed{...}$$` 给出，作为全章骨架。
5. **通用性优先**：能给出跨题型本质就先给（ε-N/ε-δ 局部逼近、行/列空间维数、加权分解、分布函数的统一语言），再落具体题型操作。
6. **应试三件套（侧重应试）**：每个考点在本质之后必须标注 **考频**（⭐⭐⭐ 每年必考 / ⭐⭐ 高频 / ⭐ 低频）、**题型**（选择/填空/解答 + 常见问法）、**得分步骤**（解答题按踩分点分步，保住步骤分）。只整理而没有应试信息的考点笔记 = 半成品。

### 反例 vs 正例

| ❌ 反面（从题型出发） | ✅ 正面（从本质出发） |
| :--- | :--- |
| "求极限的七种方法：①四则 ②洛必达 ③等价无穷小 ④夹逼 ⑤单调有界 ⑥泰勒 ⑦定积分定义" | "极限的本质是 ε-N / ε-δ **局部逼近**——$x\to x_0$ 时 $f(x)\to A$ 是函数值在点邻域内的无限趋近；七种方法只是这一本质在不同函数形态下的操作化。" |
| "矩阵的秩的三种求法：初等变换 / 子式 / 特征值……" | "矩阵的秩是**行/列空间维数**这一几何不变量的代数刻画；初等变换求秩只是把这一本质落到计算。" |
| "全概率公式解题四步：①找划分 ②求先验 ③求似然 ④加权求和……" | "全概率公式是**'分情况讨论'的数学化**——用完备事件组把复杂样本空间分解为互斥子空间再加权；难点不在公式本身，而在构造完备事件组。" |

### 落地检查

- 章节主笔记：`[!abstract]` 为「本质 → 考点」形式；`## 0. 汇总速查` 之前已有本质句；每个 `## N.` 节先数学定义 / boxed 公式，后题型操作。
- 专题 / 冲刺 / 公式汇总：同样第一节先本质。
- 决策树 / 题型表（`常见题型与解题路径`）放在本质与定义**之后**。
- **应试三件套**：`## 0. 汇总速查` 与每个 `## N.` 节体现考频 / 题型 / 得分步骤（见 8.7 应试规范）。

### 清楚易读（可读性标准）

> **目标笔记必须让读者一眼看懂**。本质优先解决"讲什么"，此处解决"怎么讲清楚"。生成 / 格式化每篇笔记时逐条自查。

- **先定义后操作**：每节先给定义 / 本质，再给题型操作——同一概念的展开顺序全篇一致。
- **表格优先**：能用表格说明的不用长段落（列对齐、要点短语、考频列）；表格优于段落文本。
- **boxed 突出骨架**：每节核心公式用 `\boxed{}`，公式旁紧跟**一句话解释**——禁止只堆公式不给含义。
- **callout 点读**：易错用 `[!danger]`，口诀 / 快捷法用 `[!tip]`，陷阱用 `[!warning]`，概念理解用 `> [!note] 理解 ·「口诀」`（格式规范见 `math-note-generator` SKILL「7. 理解注释」）——重点一眼定位。
- **30 秒可扫读**：每节控制在可快速扫读的长度；超过 200 行的笔记按子主题拆分或下沉为专题。
- **术语一致**：同一概念全库用同一名称；别名进 `aliases` frontmatter，正文不混用。

## 四、三向解题法（OPD）与精简风格

### 4.1 三向解题法（OPD）

在解题方法 / 决策树部分可融入 OPD 三向框架（先观察目标，再检索思路，最后检查细节）：

| 法则 | 英文 | 含义 | 在笔记中的表达方式 |
|:---|:---|:---|:---|
| **O — 盯住目标** | Observe | 去掉细节，锁定题目要求解的核心问题 | 题型识别 → 一句话定位目标 |
| **P — 检索思路** | Process | 正向（条件出发）/ 反向（结论反推）/ 双向 | 方法选择 → 决策树分支 |
| **D — 细节处理** | Detail | 挖掘隐藏条件、参数讨论、边界情况 | 易错点 → 特殊情形讨论 |

> [!tip] 思路打不开时的两句关键话
> 1. "再看一遍题目，问自己是否用到了所有已知条件和结论？"
> 2. "各种思路呼之欲出但用不上，或结论显而易见时，考虑使用反证法。"

### 4.2 精简风格（去废话）

笔记只承载知识点。**禁止**生成以下非知识点内容：

- ❌ "本篇定位 / 使用地图" 等自我介绍式导语块
- ❌ `## 张宇点睛归纳` 章节、`三句真经`、`一句话总纲` 等总结性套话
- ❌ `> [!danger] 考场常见失误清单`（与已出现的易错表重复，属冗余）
- ❌ `> [!tip] 张宇金句：xxx` 等名人金句 / 鸡汤
- ❌ `[!note] 防焦虑：…` 等安抚性措辞（考情范围直接写"以下数一不考"）
- ❌ `本篇补全 / 全库…未单列 / 本篇只给 / 【核心交付物】` 等自我指涉注释
- ❌ 待补充节前的提示语"已补充的内容请从这里删去"

**允许保留**：`[!abstract]` 本质→考点、`[!tip]` 口诀 / 踩分步骤、`[!danger]` 易错、`> [!note] 理解·` 概念注释、`> [!note] 顿悟·` 顿悟记录、`[!example]` 例题、`## 一题多解`（本质度/稳健度/考场速度表）、错题归因笔记（§1 错误思路还原属**思维外化内容**而非废话，精简时不得删）、OPD 决策树、`## 知识关联`、`## 待补充` 勾选项。

## 五、待补充记录机制

> 从 `engineering-math-organizer` 移植。**记录笔记可待补充的内容，后续已补充删去记录。**

- **位置**：每篇章节主笔记 + 每科目综合总结的末尾各带一个 `## 待补充` 节（**必带**）；公式汇总 / 专题 / 冲刺在存在明显未来深化方向时可选加。
- **格式**：

```markdown
## 待补充

- [ ] {未来可深化的方向}
- [ ] 概率论 ch32：连续型随机变量函数分布的雅可比公式专项
```

- **规则**：
  1. **新增**：当某个方向"未来可能深挖但当前未写"时，追加一条 `- [ ]`。
  2. **完成即删**：当某待补充项被展开成真实笔记（专题 / 冲刺 / 公式汇总 / 二级结论）后，**必须**从原列表**删除该行**，并在对应笔记的 `知识关联` 中加入新笔记 wikilink。
  3. **深化后回访**：完成一个方向后，回到对应 章节主笔记 + 综合总结，删除已完成的待补充项。
  4. **迭代升级（活档案）**：同类错因沉淀 ≥3 条 → 合并为「错题归因」专题或并入相关冲刺补充；同类顿悟 ≥3 条 → 升级为「思路轨迹」专题或二级结论 `.21`。升级后删去各待补充行，并在知识关联回链新笔记。
- **待补充 vs 真实笔记**：待补充是"想法清单"（未完成态）；一旦落实为笔记，就从未完成态转为已完成态，删去记录。审计报告中的 `- [ ]` 项用于人工核对是否已落实。
- **对概率论的意义**：`30、概率论综合/` 与 32–36 章近乎空白，主笔记首批 `- [ ]` 待补充种子清单就是它们的第一版内容规划。

## 六、操作流程

### 6.1 模式审计（Audit）

给定一个科目（高等数学/线性代数/概率论），执行以下审计：

**步骤 1：建立期望模式**
基于线性代数 `02、线性代数/` 的完整目录结构，生成该科目期望的文件列表。

期望清单应包括：
- 每个章节应有公式汇总 `{ch}.00`
- 每个章节应有二级结论 `{ch}.21`
- 每章应有 1–3 个专题 `{ch}.01–{ch}.09`
- 每章应有 1–3 个冲刺补充 `{ch}.82–{ch}.89`
- 综合目录下的综合总结 `{subject-number}0.00`
- 错题归因 `{ch}.31` / 思路轨迹 `{ch}.41` **按需**（不设期望数量；出现高频错题/顿悟时创建，应试高价值）
- 所有 wikilink 应指向存在的文件

**步骤 2：扫描实际文件**
递归列出目标科目目录下的所有 `.md` 文件。

**步骤 3：比对差距**
逐项比对期望 vs 实际，生成差距报告。审计范围除文件缺失外，还需覆盖：

| 审计维度 | 检查内容 |
|:---|:---|
| ❌ 文件缺失 | 公式汇总 / 二级结论 / 专题 / 冲刺 缺失 |
| ⚠️ 编号冲突 | 重复编号（如 `18.00` 两份）、`17.1` 类非规范编号 |
| ⚠️ 待补充缺失 | 章节主笔记 / 综合总结 是否有 `## 待补充` |
| ⚠️ 本质优先不达标 | `[!abstract]` 与首节是否符合「本质→考点」 |
| ⚠️ 应试三件套缺失 | `## 0. 汇总速查` / 各节缺考频、题型或得分步骤标注（见 8.7） |
| ⚠️ 真题关联缺失 | 近十年常考考点旁无 `20XX-数一-T{n}` 标注或真题链 |
| ℹ️ 思维外化（增强·非阻断） | 错题归因/思路轨迹缺失不扣分；抽查主笔记/专题是否有个人化理解（顿悟/一题多解/理解轨迹），缺则记入待补充 |
| ⚠️ 死链 | 引用目标不存在 |

**步骤 4：输出审计报告**
将差距报告以表格形式呈现，并按"优先级"排序。用 `> [!abstract]` 框出最重要的 3 条行动项。

### 6.2 补全生成（Generate）

按优先级从高到低补全缺失笔记：

1. **公式汇总 `{ch}.00`** — 优先为缺少的章节创建
2. **综合总结 `{subject-number}0.00`** — 为概率论从零创建，为高数补充缺失章节
3. **二级结论 `{ch}.21`** — 从主笔记中提炼公式级结论
4. **150冲刺补充 `{ch}.82+`** — 为缺少的章节创建 1–3 个
5. **专题 `{ch}.01+`** — 为缺少的章节补充
6. **130必会 `{ch}.71`** — 高数专有，为缺少的章节补充

> **按需（非补全目标）**：错题归因 `{ch}.31` / 思路轨迹 `{ch}.41` —— 用户提供真实错题/顿悟时创建；同类沉淀 ≥3 条升级为专题/二级结论。⚠️ 基于用户真实经验，用户未给细节时**先问**，不得编造"我的错误/顿悟"。

**生成原则**：
- 必须读取目标章节的主笔记，提取核心公式和结论
- 必须读取已有的综合总结（如有），保持风格一致
- **先记待补充、后删行**：生成新笔记前，先在对应章节主笔记 + 综合总结的 `## 待补充` 记录该方向；生成完成后删除已完成的待补充项，并在 `知识关联` 加入新笔记链接
- 所有新笔记按「考点本质优先」开头（先定义 / boxed，后题型；`[!abstract]` 为「本质 → 考点」）
- 生成的 wikilink 必须验证目标文件存在（Obsidian 按 basename 全局解析）
- 用 `>` 引用和 `[!tip]`/`[!danger]`/`[!warning]` 标注重点和易错
- 公式用 `\boxed{}` 包裹核心公式
- 表格优先于段落文本（一眼看清）
- **精简风格**：不写"本篇定位"导语，不生成"张宇点睛归纳 / 三句真经 / 考场常见失误清单 / 张宇金句 / 一句话总纲 / 防焦虑"等非知识点内容；开头直接 `[!abstract]` 本质定位 + 正文
- **应试导向（侧重应试）**：每个考点标考频（⭐⭐⭐/⭐⭐/⭐）与题型；解答题给 `> [!tip] 踩分步骤`；有真题出处的注明 `20XX-数一-T{n}`，线代可链 `线性代数解题技巧/03、真题实战`

## 八、格式化规范

### 8.1 YAML Frontmatter 规范

```yaml
---
tags: [数学一, {科目}, {章名/专题名}]
# 可选字段：
aliases: [{简称1}, {简称2}]
created: {YYYY-MM-DD}
modified: {YYYY-MM-DD}
---
```

### 8.2 表格规范

- 使用 `:---` / `:---:` / `---:` 控制对齐
- 表格内 `$...$` 中的裸 `|` 会被 Markdown 解析为列分隔符，导致公式断裂。绝对值改用 `$\lvert x\rvert$`，范数用 `$\lVert x\rVert$`，向量模用 `$\lvert\vec{v}\rvert$`，条件概率用 `$\mid$`
- 表格第一行用大写加粗标题行
- 表格内容优先用短语而非长句

### 8.3 Callout 规范

| 类型 | 用途 | 示例 |
|:---|:---|:---|
| `[!abstract]` | **一句话定位（考点本质优先）** | `[!abstract] 一句话定位` 写 `**{本质} → {考点}**` |
| `[!tip]` | 记忆技巧、快捷方法 | 口诀、速算法 |
| `[!danger]` | 易错、雷区 | 常见错误、条件遗漏 |
| `[!warning]` | 注意事项 | 命题陷阱 |
| `[!note]` | 补充说明 | 延展信息 |
| `[!example]` | 示例 | 经典例题 |
| `[!summary]` | 归纳总结（仅知识点结论浓缩，不写"三句真经/一句话总纲"式总结） | `[!summary] 结论要点` |

### 8.4 公式规范

- 核心公式用 `\boxed{}` 包裹
- 公式编号可选但非必须
- 长公式用 `\begin{aligned}` 换行对齐
- 行内公式用 `$...$`，独立公式用 `$$...$$`

### 8.5 链接规范

- 内部链接用 `[[wikilink]]` 格式（不用 Markdown `[]()`）
- 指向子节用 `[[文件#标题|别名]]`
- 综合总结中的每章引用格式：`章节笔记：[[XX、章名]] \| 公式速查：[[XX.00、章名公式汇总]]`
- Obsidian 按 **basename 全局解析** wikilink，新建笔记不得与已存在 basename 冲突

### 8.6 待补充规范

- 章节主笔记 + 综合总结末尾必带 `## 待补充` 节
- 项格式：`- [ ] {待补充内容}`（checkbox）
- **完成即删除该行**，并在 `知识关联` 加入新笔记链接

### 8.7 应试规范（侧重考研应试）

**考频标准**：⭐⭐⭐ 近十年真题 ≥5 次或每年必考；⭐⭐ 高频（≥3 次）；⭐ 低频（<3 次）。主笔记 `## 0. 汇总速查` 的考频列与每个 `## N.` 节标题旁的星标使用同一标准。

**题型标注**：每个考点写明主要考查形式——选择 / 填空 / 解答，以及常见问法（"求极限""判断收敛"…），帮助识别"看到什么 → 用什么"。

**得分步骤**：解答题按**踩分点**分步书写——结论式公式先行 → 关键中间量 → 最终答案——确保算错也能拿步骤分；用 `> [!tip] 踩分步骤` 标注。

**真题关联**：考点旁标注近十年真题出处，格式 `20XX-数一-T{题号}`（如 `2023-数一-T16`）；有 `真题实战` 笔记的（如线代 `线性代数解题技巧/03、真题实战`）直接链向它。
