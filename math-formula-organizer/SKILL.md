## 数学笔记的本质：思维外化 · 活档案

> 公式笔记是"**可信、可溯、可用**"的公式资产，不是公式的堆放。每个公式要能回答三问——**为什么信它**（来源/推导）、**哪里容易用错**（错因/坑）、**和谁连着**（公式地图）。

五条贯穿性原则（公式版）：

1. **思维外化，非知识搬运**：公式不只抄，要记录"为什么这样用"（记忆法/来源/理解）。
2. **顿悟必留痕**：公式间的联系、统一视角的顿悟是资产（`> [!note] 顿悟 ·「...」` 或思路轨迹笔记）。
3. **错题归因到思维漏洞**：公式误用是最高频失分点，从误用反推对公式理解的漏洞。
4. **可追溯**：每个公式标注来源 + 适用条件 + 坑。
5. **活档案·可迭代**：公式随使用迭代——补变体、合并同类、升级专题。

> 📖 完整公式版哲学、两类新笔记模板（错题归因/思路轨迹）→ **`references/thinking-archive.md`**。创建这两类笔记前必须读它。

## 排版铁律（从 CLAUDE.md 继承 + 数学公式特有）

### 三条基础规则

| # | 规则 | 说明 |
|:---|:---|:---|
| **1** | 表格内禁用裸 `\|` | **表格 `$...$` 内 `|` 会被解析为列分隔符**。条件概率用 `$\mid$`，绝对值用 `$\lvert x\rvert$`，范数用 `$\lVert x\rVert$`，集合基数用 `$\lvert A\rvert$`。详见「排版铁律 §1」对照表 |
| **2** | 盒装核心公式 | 必背公式用 `\boxed{}` 包裹，一眼识别 |
| **3** | 表胜于文 | 能用表格就不用段落。对比信息、分类信息优先用表格 |

### 数学公式排版

| 场景 | 写法 | 示例 |
|:---|:---|:---|
| 行内公式 | `$...$` | `$x \to 0$` |
| 独立公式 | `$$...$$` | `$$\lim_{x \to 0} \frac{\sin x}{x} = 1$$` |
| 盒装公式 | `$$\boxed{...}$$` | `$$\boxed{\int_a^b f(x)dx}$$` |
| 表格内公式 | `$...$` | `$\frac{0}{0}$ 型` |
| 分段函数 | `\begin{cases}` | `$$\begin{cases} f_x = 0 \\ f_y = 0 \end{cases}$$` |
| 对齐公式 | `\begin{aligned}` | `$$\begin{aligned} x &= a+b \\ y &= c+d \end{aligned}$$` |

### Callout 使用规范（仅 5 种）

| Callout | 用途 | 示例场景 |
|:---|:---|:---|
| `> [!tip]` | 解题技巧、口诀 | 拉格朗日方程组的对称消元技巧 |
| `> [!warning]` | 注意事项 | 等价无穷小只在乘除中使用 |
| `> [!danger]` | 易错陷阱 | 拉格朗日乘数法不判极大型 |
| `> [!example]` | 例题 | 具体计算示例 |
| `> [!note]` | 补充说明 | 公式的推导背景 |

## 核心工作流

### 工作流 1：章节格式化与汇总速查

**触发条件**：用户要求补充/格式化某个章节、添加汇总速查、统一风格。

**目标**：每个章节笔记必须具备 `## 0. 汇总速查`（位于文件最顶部），包含四个标准子节。

#### 章节笔记标准结构

```markdown
# {章节标题}

---

## 0. 汇总速查

### 核心公式速查

| 公式名 | 公式 | 备注 |
|:---|:---|:---|
| ... | $...$ | ... |

### 常见题型与解题路径

| 题型 | 关键步骤 |
|:---|:---|
| ... | ... |

### 易错点提醒

| 易错点 | 正确做法 |
|:---|:---|
| ... | ... |

---

## 1. {第一节标题}【考频标注】

...

---

## 知识关联

- [[上级目录文件|返回上级]]
- [[00、目录/00、总目录|返回总目录]]
```

**汇总速查编写原则**：
- **核心公式速查**：提取本章最核心的 5-10 个公式，一个公式一行。要求：看一眼就能想起整章骨架
- **常见题型与解题路径**：列出 5-8 种题型，每种用一句话给出关键步骤。格式：`题型 | 关键步骤`
- **易错点提醒**：列出 5-8 个最高频错误，每个用 `易错点 | 正确做法` 对照。要求：具体到操作层面，不说空话

**操作步骤**：

1. **Read** 现有章节文件，分析已有内容
2. **检查是否已有 `## 0. 汇总速查`**：
   - 若有 → 评估内容是否完整（三个子节 + 覆盖面）
   - 若没有 → 从详细内容中提炼，添加到文件最顶部
3. **补充缺失公式/定理**：对照考研大纲，检查是否有遗漏的重要公式
4. **更新知识关联**：确保有返回上级和总目录的链接
5. **验证**：表格无裸 `|`、公式正确、链接可解析

**考频标注规则**（在 H2 标题中）：
- `【必考】`：几乎每年必出
- `【高频考点】`：多数年份考查
- `【重要】`：核心概念，间接考查
- 不标：非重点，了解即可

**专题笔记编写原则**：
- **方法总览表**必须放在最前面，让读者 3 秒定位
- **每个子主题至少一个例题**，例题必须完整（题目 → 解 → 答案）
- **例题要有代表性**：选最能体现该方法的典型题
- **易错点要具体**：不写"注意计算"，要写"求驻点后忘记计算 $\Delta = AC - B^2$"
- **检查清单**：3-6 条，做题前逐条确认

**距离/最值类问题技巧**：
- 永远用距离的**平方**作为目标函数，省去根号求导
- 能用代入消元就不用拉格朗日乘数法
- 闭区域最值必须内部 + 边界 + 比较三步走

## 常见问题速查

### Q：汇总速查的"核心公式"该选哪些？

选**本章最核心的 5-10 个公式**，标准：
1. 每年必考的基础公式（如等价无穷小、导数公式）
2. 本章独有的定理/判别法（如 AC-B² 判别法）
3. 与其他章节链接的枢纽公式（如格林公式连接线积分和二重积分）

不要选：过于琐碎的变形、其他章节已覆盖的公式。

### Q：专题笔记和章节笔记的区别？

| 维度 | 章节笔记 | 专题笔记 |
|:---|:---|:---|
| 定位 | 知识覆盖（全） | 解题突破（深） |
| 结构 | 公式罗列 + 简要说明 | 方法总览 + 例题 + 易错点 |
| 篇幅 | 100-200 行 | 150-300 行 |
| 例题 | 可以没有 | 必须有，每个子主题至少一个 |
| 目标 | 查公式 | 学方法 |

### Q：什么时候需要创建专题？

满足任一条件：
- 跨 2+ 章节的高频考点（如 Green/Gauss/Stokes 三公式综合）
- 某类题型在真题中反复出现（如中值定理证明题）
- 用户明确说"这个需要专门整理"

### Q：什么时候需要二级结论？

章节笔记中有 ≥5 个 `\boxed{}` 公式，且用户需要考前快速翻阅时。
