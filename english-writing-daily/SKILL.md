# 考研英语一作文每日一练

> 每日一道真题作文练习，配高分范文（杜绝偏词）+ 逐层解析。按专题出题，每7篇自动生成一篇类型总结。
> 直击考研英语一写作高分核心：**内容切题、语言准确、结构清晰、逻辑自然**。

## 核心规则（最优先遵循）

1. **存储路径**：所有练习笔记保存在 `考研/英语一/作文/每日一练/`
2. **文件命名**：`NN-YYYY-MM-DD-作文类型.md`，如 `01-2026-07-19-建议信.md`
3. **出题方式**：根据用户当前学习的**作文专题**出题（不轮换），如用户提到"练建议信"就一直出建议信
4. **图画/图表**：调用 Excalidraw 生成插图嵌入笔记
5. **每7篇总结**：当 `每日一练/` 中笔记数量达到7的倍数时，在 `考研/英语一/作文/总结/` 生成一篇该类型的总结合并笔记

### 1.4 评分标准速查（大作文）

| 维度 | 满分 | 高分特征（5档 17-20分） |
|:---|:---:|:---|
| 内容（Content） | 8 | 切题、覆盖所有要点、论证充分有深度 |
| 语言（Language） | 8 | 语法准确、词汇丰富自然、句式多样 |
| 结构（Structure） | 4 | 层次分明、衔接自然、格式规范 |

**注意事项**：
- 近年 **反模板化** 趋势明显。模板套话（"Every coin has two sides"、"With the development of society"）会被压低分数
- 真正的得分解是：**内容深度 > 词汇难度 > 句型复杂**
- 卷面工整也是隐形加分项（技能层面我们确保内容质量）

## 二、核心写作原则（严格执行）

### 原则一：不得使用偏词（词汇选择标准）

**定义**：参考范文中的词汇必须控制在 考研英语大纲词汇 范围内，不得使用：
- ❌ GRE / 雅思8分以上级别词汇（如 ameliorate, ubiquitous, exacerbate, paradigm, dichotomy, pernicious, myriad, recondite）
- ❌ 生僻同义替换（如 "非常多" 不用 myriad，用 countless / a growing number of）
- ❌ 过度文学化的表达

**正确示范**（自然的高分表达）：

| 场景 | ❌ 偏词（避免） | ✅ 自然高分（使用） |
|:---|:---|:---|
| 表示"重要" | paramount, pivotal | significant, essential, crucial |
| 表示"问题" | predicament, dilemma | challenge, issue, problem |
| 表示"帮助" | facilitate, ameliorate | help, promote, contribute to |
| 表示"因此" | accordingly, thus | therefore, consequently |
| 表示"很多" | myriad, numerous | a great many, a growing number of |
| 表示"必要" | imperative, requisite | necessary, essential |
| 表示"改变" | transform, revolutionize | change, improve, shape |
| 表示"认为" | opine, contend | believe, argue, hold that |

**核心思想**：高分作文靠的是 **准确 + 自然 + 恰到好处的丰富**，而不是堆砌生僻词。一个精确使用 "significant" 的作文，远胜于硬塞 "paramount" 却用错的作文。

### 原则二：高分作文质量标准

参考范文需同时满足以下五点：

1. **切题精准**：完全覆盖题目要求的所有要点，不偏不离
2. **逻辑自然**：段落之间有清晰的逻辑推进（不是简单罗列Firstly/Secondly），论证使用因果、对比、举例等
3. **句式多样**：
   - 长短句结合
   - 适当使用定语从句、状语从句、倒装、强调句等
   - 但以准确为前提，宁简勿错
4. **词汇丰富**：
   - 避免重复使用同一个词（如用 "important / crucial / essential / significant" 交替）
   - 使用恰当的搭配（如 "pose a challenge" 替代 "is a problem"）
   - 使用合适的过渡词（如 "moreover / furthermore / in addition" 交替）
5. **无模板痕迹**：避免 "With the development of society", "Every coin has two sides", "As far as I'm concerned" 等陈词滥调

### 原则三：详细解析格式

每篇参考范文必须附以下四部分解析：

| 解析板块 | 内容 | 篇幅 |
|:---|:---|:---:|
| 一、内容分析 | 是否切题、要点是否覆盖、论证是否充分 | ~80字 |
| 二、语言亮点 | 精选3-5个用词/句式的亮点，说明好在哪里 | ~100字 |
| 三、结构分析 | 段落组织、逻辑推进方式、衔接手段 | ~80字 |
| 四、实用句型 | 提取文中可复用的句型，制成表格并说明用途 | 3-5个句型 |

## 三、出题方案（基于专题）

### 3.1 出题逻辑

不再使用固定轮换。出题方式如下：

1. **用户指定专题** → 按用户说的专题出题（如"练建议信"就一直出建议信）
2. **用户未指定专题** → 询问用户想练什么专题，或推荐当前最需要练习的题型
3. **同一专题连续出题**时，每次变换具体话题方向，避免重复
   - 如建议信系列：学习建议→生活建议→活动建议→课程建议→实习建议→图书馆建议→综合建议

### 3.2 专题与真题话题对照

使用下表选择该专题下的具体话题方向：

| 回复信/介绍信 | 回复咨询、介绍校园、介绍专业、介绍活动安排 |

### 3.3 确定编号的方法

执行时使用以下逻辑确定编号：
1. 读取 Vault 中 `考研/英语一/作文/每日一练/` 目录下的现有笔记
2. 按文件名中的数字编号排序，取最大编号 N
3. 下一篇编号 = N + 1（两位数补零，如 `01`、`02` ... `99`）
4. 如果该目录不存在，先创建目录，编号从 `01` 开始

### 3.4 每7篇触发总结

当 `每日一练/` 中笔记数量 ≥ 7 篇时，在生成下一篇之前执行：
1. 统计最近7篇练习的类型分布
2. 在 `考研/英语一/作文/总结/` 创建总结笔记
3. 总结笔记包含：
   - 这7篇练习了什么类型/话题
   - 各类型的核心写作框架
   - 高频错误/注意事项汇总
   - 实用句型汇总表
   - 下阶段学习建议
4. 总结命名：`XX篇总结-作文类型.md`，如 `07篇总结-建议信.md`

## 五、技能执行流程

当被用户触发时，按以下步骤执行：

### Step 0：检查是否需要生成总结

读取 `考研/英语一/作文/每日一练/` 下的笔记数量：
- 如果数量 ≥ 7 且是7的倍数（7、14、21...），且 `考研/英语一/作文/总结/` 下还没有对应批次的总结
  → 先执行"生成总结"（见 Step 6），再继续执行后续步骤

### Step 1：确定编号和专题

1. 检查 Vault 目录 `考研/英语一/作文/每日一练/` 是否存在，不存在则创建
2. 读取已存在的笔记，按文件名前两位数字排序获取最大编号 N
3. 下一篇编号 = N + 1（两位数，补零）
4. 根据用户当前学习需求确定作文专题：
   - 用户指定了专题 → 按用户说的
   - 用户未指定 → 询问用户想练什么
   - 同一专题连续出题时，每次变换具体话题方向

### Step 2：生成题目

1. 根据确定的专题和话题方向，从历年真题库中选取或衍生题目
2. 题目风格需与真题一致：
   - **小作文**：给出情景设定 + 写作任务指令
   - **大作文（图画）**：创建 Excalidraw 图画 + 提纲要点
   - **大作文（图表）**：创建 Excalidraw 图表 + 提纲要点
3. 在 "source" 字段标注参考的真题年份

### Step 3：创建 Excalidraw 图片（大作文必做）

对于大作文，调用 Excalidraw 创建可视化插图：
1. 创建文件 `考研/英语一/作文/每日一练/NN-YYYY-MM-DD-作文类型-图画.excalidraw`
2. 绘制图画或图表，确保风格与真题一致
3. 在笔记中通过 `![[...]]` 嵌入
4. **注**：如果当前环境无法直接创建 Excalidraw 文件，至少提供详细的文字描述供用户参考绘制

### Step 4：提供写作思路

1. 审题要点提示
2. 建议的段落结构
3. 推荐可用的词汇/表达
4. 这部分是**学习指导**，不是要把学生框死

### Step 5：撰写参考范文 + 解析

严格执行 **原则一（不得使用偏词）** 和 **原则二（高分标准）**：
1. 先用中文想清楚每段要说什么（确保内容质量）
2. 用自然、准确、有变化的英文表达
3. 全文通读检查：有没有偏词？有没有模板痕迹？句式是否多样？

按 **原则三** 的要求完成四部分解析：
1. 内容分析
2. 语言亮点
3. 结构分析
4. 实用句型表

### Step 6：生成总结（每7篇触发）

当笔记数量达到7的倍数时，在 `考研/英语一/作文/总结/` 创建总结笔记：
1. 统计最近7篇练习的类型分布
2. 提取各篇的核心写作框架和句型
3. 汇总常见错误和注意事项
4. 给出下阶段学习建议
5. 总结文件命名：`NN篇总结-作文类型.md`（NN为结束编号）

### Step 7：保存笔记

1. 练习笔记保存到 `考研/英语一/作文/每日一练/NN-YYYY-MM-DD-作文类型.md`
2. Excalidraw 图片保存到同目录 `NN-YYYY-MM-DD-作文类型-图画.excalidraw`
3. 总结笔记保存到 `考研/英语一/作文/总结/`
4. 向用户展示今日练习的完整内容

## 七、使用示例

### 示例 1：用户说"练练建议信"

→ 专题 = 建议信 → 检查 `每日一练/` → 编号 = 最大编号+1 → 出建议信题目（变换话题方向，不与前面重复） → 创建笔记+解析 → 如果是第7/14/21篇，先创建总结

### 示例 2：用户说"帮我出一道关于坚持的图画作文"

→ 专题 = 个人品质（坚持）→ 大作文 → 创建 Excalidraw 登山图 → 出题+范文+解析 → 保存笔记和图片

### 示例 3：用户说"最近图表作文考得多，练练图表"

→ 专题 = 图表作文 → 大作文 → 创建 Excalidraw 柱状图/线图 → 出题+范文+解析 → 保存

### 示例 4：用户未指定专题，说"今天练什么"

→ 先问用户想练什么专题 → 如果用户说"随便"，推荐当前最薄弱或最新趋势的题型（如图表作文）

**注意**: 每篇笔记的编号连续递增（01→02→03...），不受专题切换影响。当用户从一个专题切换到另一个专题时，编号仍然顺延。
