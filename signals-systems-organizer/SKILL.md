# 信号与系统笔记体系（本质优先）

> 这套笔记的写作顺序是：**先讲清楚"为什么"，再给"怎么做"**。任何一篇方法笔记，读者扫完第 1 节就应该理解这个方法存在的理由；后续章节才是操作步骤、公式与例题。

---

## 核心哲学：本质优先

| 原则 | 含义 |
|:---|:---|
| **本质先行** | 每篇方法笔记的 `## 1` 必须是「本质」章节，讲"为什么/直觉/坐标系"，而不是公式堆砌 |
| **操作殿后** | 操作步骤、公式表、例题放在本质之后，作为"落地"部分 |
| **练习收尾** | 一个主题（如 4、LTI时域分析）结束时，配一份「综合练习」，按考点全覆盖 |
| **一法一义** | 每篇笔记只讲一个方法/概念，拆开写，不混 |

> [!tip] 本质优先的好处
> 读者先建立"心理模型"，再记公式——记忆负担小、迁移能力强。考试时即使忘公式，也能从本质推出来。

## 一、本质的写法（为什么层）

### 1. 本质章节的标准骨架

```
## 1. 本质：<一句话主题>
### 1.1 一句话本质
> [!abstract] 本质
> 用 1-2 句话说出这个方法"在做什么、为什么成立"。
$$\boxed{核心公式（一张图看懂本质）}$$
### 1.2 / 1.3 / 1.4 关键洞察（2-4 个）
用表格或短推导讲"为什么"，每个洞察回答一个"为什么"。
### 1.x 一句话升华
> [!tip] 记忆法 / 升华
> 用一个类比或一句话把本质钉进脑子。
```

### 2. 常用的"为什么"视角（写本质时的弹药库）

| 视角 | 问的问题 | 举例 |
|:---|:---|:---|
| **坐标系/投影** | 这个变换把信号搬到了什么基上？系数是什么？ | FS 系数 = 信号在复指数正交基上的坐标 |
| **物理直觉** | 物理上发生了什么？ | 冲激 = 踢系统一脚，t>0 后自由演化 |
| **运算降维** | 换域之后复杂运算变简单了吗？ | 卷积 → 乘法；微分 → 乘 $jk\omega_0$ |
| **类比线性代数** | 类比矩阵/向量空间 | LTI 算子 = 矩阵，$e^{st}$ = 特征向量，$H(s)$ = 特征值 |
| **与变换域联系** | 时域做法是哪个 s 域/z 域操作的镜像？ | 冲激平衡法 = 部分分式展开的时域原生态 |
| **对偶性** | 连续/离散、时域/频域怎么对偶？ | CTFS 积分→DTFS 求和，$1/T$→$1/N$ |

> 每篇本质至少覆盖 2 个视角，但不要硬凑——写最关键的 2-4 个。

### 3. 本质章节的质量检查

- [ ] 读完 1.1 能复述"这个方法为什么存在"？
- [ ] 每个洞察是否回答了一个具体的"为什么"？（而不是复述公式）
- [ ] 是否有类比或一句升华？（矩阵、坐标系、分光镜、身份证…）
- [ ] 是否有 boxed 核心公式？（本质要"一眼可见"）

**练习生成规则**：
- 每个方法笔记至少出 1 题；重难点（重根陷阱、$0^+$ 跳变、循环卷积…）单独出陷阱题；
- 难度标注：🟢 直接套公式 / 🟡 需一步变形 / 🟠 综合 2+ 方法；
- 每题解析含**验证或交叉检验**（数值回代、变换域复核、帕塞瓦尔互验）；
- 末尾附**考点覆盖总表**（考点 | 笔记 | 题号），保证无遗漏。

## 五、排版规范

### 六条铁律

| # | 原则 | 实操 |
|:---|:---|:---|
| 1 | 一节一义 | 每个 H2 只讲一个概念 |
| 2 | 表胜于文 | 3 列以内、5 行以上的对比必须用表格 |
| 3 | 盒装公式 | 核心公式用 `\boxed{}` |
| 4 | 装饰无罪，啰嗦有罪 | 仅 5 种 callout：`abstract`（本质/定义）、`tip`（口诀）、`warning`（注意）、`danger`（陷阱）、`summary`（归纳） |
| 5 | H1→H2→H3 仅三层 | 不用 H4/H5/H6 |
| 6 | `---` 分割线 | 每个 H2 之间用 `---` 分隔 |

### 表格内竖线（防表格断裂）

**表格单元格的 `$...$` 内严禁出现裸 `|`**——它会被误判为列分隔符。

| 场景 | ❌ 错误 | ✅ 正确 |
|:---|:---|:---|
| 绝对值 | `$\|x\|$` | `$\lvert x\rvert$` |
| 范数 | `$\|X\|$` | `$\lVert X\rVert$` |
| 条件概率 | `$P(B\|A)$` | `$P(B\mid A)$` |
| 表格内 wikilink 别名 | `[[a\|别名]]` 内裸 `\|` 需写成 `\\|` | `[[A\|别名]]` 中 `|` 须转义为 `\|` |

> 表格内 wikilink `[[目标\|别名]]` 必须用 `\|` 转义；表格外的 wikilink 用普通 `|`。


## 六、核心工作流

### 工作流 1：从本质补充/升级一篇方法笔记

1. **Read** 现有笔记，分析当前第 1 节；
2. 若第 1 节不是「本质」→ 插入 `## 1. 本质`（按第一节骨架），原内容顺延编号（原 `## 1` → `## 2`，`### 2.1` → `### 3.1` 等）；
3. 用「为什么视角」写本质，至少 2 个洞察 + 1 句升华；
4. 更新 `知识关联`（补兄弟笔记、综合练习、总目录）；
5. 同步 MOC（`00、奥本海姆总目录.md`）若有目录变化。

### 工作流 2：创建解题方法系列（如 6、拉普拉斯变换）

1. 建目录 `12、基础知识/N、{主题}/`；
2. 拆分方法清单（N.1 定义/直觉、N.2 …、N.m 综合练习）；
3. 逐篇按「方法笔记模板」写（本质优先）；
4. 全部完成后写 `N.m+1、{主题}综合练习.md`；
5. 更新 MOC 解题方法表 + `updated` 日期。

### 工作流 3：生成综合练习

1. 列出该主题全部考点（对应每篇方法笔记）；
2. 每考点出 1-2 题，标难度；重难点出陷阱题；
3. 写完整解析（含验证/交叉检验）；
4. 加「易错提醒」+「考点覆盖总表」。

### 工作流 4：健康检查（每次操作后必做）

见下节。

### 2. 表格裸竖线检测

用 Python 逐行扫描表格：
- `$...$` 内出现裸 `|`（`|` 前无 `\`）→ 违规；
- `[[...]]` 内出现裸 `|` 别名 → 违规（表格内必须 `\|`）。
