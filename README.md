# Obsidian-Skill

A lightweight Obsidian plugin that adds small automation and productivity helpers to improve note workflows.

## Features
- Quick configurable commands and actions
- Simple templates and snippets
- Lightweight, minimal configuration

## Installation
1. Copy the plugin folder to your vault's `.obsidian/plugins/Obsidian-Skill/`
2. Enable "Obsidian-Skill" in Obsidian's Community Plugins settings

## Usage
- Open the Command Palette and run available "Obsidian-Skill" commands
- Configure options in the plugin settings to customize behavior
